# Bricolage Grotesque

`bricolage-grotesque-latin-variable.woff2` is the unchanged Latin variable font
from `files/bricolage-grotesque-latin-standard-normal.woff2` in
`@fontsource-variable/bricolage-grotesque` version **5.3.0** (Google Fonts v9).

- Package: https://www.npmjs.com/package/@fontsource-variable/bricolage-grotesque
- Source: https://github.com/ateliertriay/bricolage
- Distribution: https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque
- License: SIL Open Font License 1.1; the accompanying `OFL.txt` is copied verbatim.
- Axes: weight 200–800, width 75–100, optical size 12–96.

The application loads this file through `next/font/local`; it requires no font
request to a third-party service. The headline uses weight 700, optical size 12, and width 83. Its optical sizing is explicitly disabled so browser defaults do not change the approved letter character at large display sizes.
