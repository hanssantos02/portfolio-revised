# From screen to circuit

The cover introduces Hans alongside an exploded service drawing. Each plane represents one discipline. Selecting a plane changes its position and color, explains the service in plain language, and links to a relevant build. Keep the illustrative label visible. Project evidence belongs in the work section.

## Type and composition

Use self-hosted Bricolage Grotesque for names, headings, and the wordmark. Set the second phrase of the cover and section titles in the system’s Georgia italic. Arial carries descriptions, controls, and captions. The cover and section headings scale with the viewport. Below 56.25rem the drawing follows the introduction in reading order.

Ivory provides the reading surface. Cobalt marks actions and title emphasis. The deeper blueprint blue carries the drawing and inquiry section. Dark navy frames the project spreads. The grid is confined to the drawing field.

## Browsing the work

Keep service descriptions visible in open rows. In each project spread, pair an authentic screenshot or labeled hardware diagram with a short summary, its technologies, and working destinations. Place supporting details in a native Build notes disclosure. Group technologies by discipline in the personal introduction. The contact and résumé actions use ordinary links.

## Interaction

Use the current-location underline for navigation and a filled Contact link. Highlight service selection with a finite plane lift. Entry motion for project figures uses a native view timeline in supporting browsers. The page starts readable, including when JavaScript is unavailable. Reduced motion retains selection color and suppresses animation and smooth scrolling. Keep visible focus outlines and preserve the 44px control height.
